# Jerry AI Video

A simple AI video creator landing page and prompt interface.

## Deploy on Vercel
1. Upload these files to a GitHub repository.
2. Import the repository into Vercel.
3. Deploy the project.
4. Keep API keys in Vercel Environment Variables, never inside `script.js`.

## API key
The frontend does not contain an API key. Add your key securely in Vercel when the backend/API endpoint is connected.
